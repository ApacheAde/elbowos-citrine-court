# Citrine Court

Full-colour Python 3 neon squash-hoop arcade for [ElbowOS](https://x.com/ElbowOS).

Slide the gold paddle, bounce the citrine orb through the moving magenta hoop, and smash spinning gems. Miss the floor and the combo drops.

## Play

```bash
pip install -r requirements.txt
python3 citrine_court.py --play
```

Controls: A / D or arrows slide the paddle. R resets. Esc quits.

## Record a 9:16 reel

```bash
ELBOWOS_RECORD=1 python3 citrine_court.py
```

Writes a 15s 1080x1920 H.264 MP4 (needs ffmpeg).
